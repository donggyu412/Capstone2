# DreamModel


## DreamModel

### 어떤 모델인가?

인간의 감정과 기억을 바탕으로 꿈 애니메이션을 만드는 프로그램이다. 이야기·배경 이미지·오브제 이미지·사운드를 받아, 공간과 사물이 천천히 생겨나고 변하며 사라지는 영상을 만든다.

**오브제**는 책·손·그림자처럼 장면에 등장하는 사물을 뜻한다. 배경과 오브제는 각각 다른 방식으로 만들어지고, 같은 장면 안에서 어우러진다.

**완성 영상** 기·승·전·결 각 75초, 총 5분
1920 × 1080 / 30 fps / MP4 / 전달받은 사운드 포함

### 설치해야 하는 것

| 설치 항목 | 용도 |
| --- | --- |
| Python 3.12 · 필수 | DreamModel을 실행하는 프로그램 |
| Visual Studio Code · 권장 | 프로젝트 파일을 열고 코드를 확인·수정하는 프로그램 |
| NumPy · Pillow · 필수 | Python 추가 도구. 숫자 계산과 이미지 읽기에 사용 |
| OpenCV · imageio-ffmpeg · 필수 | Python 추가 도구. 이미지 처리와 영상 저장에 사용 |

추가 도구 목록은 **requirements.txt**에 있다. OpenCV의 설치 이름은 opencv-python-headless다. 별도의 AI 모델 파일이나 API 키는 필요하지 않다.

공식 설치 페이지: [Python 3.12](https://www.python.org/downloads/release/python-31210/) · [Visual Studio Code](https://code.visualstudio.com/download)

### 사용 순서

**①** Capstone2 프로젝트를 연다.
**②** 이야기·배경·오브제와 받은 음원을 준비한다.
**③** main.py에서 짧은 미리보기를 먼저 실행한다.
**④** 화면을 확인한 뒤 5분 완성본을 만든다.
**⑤** output 폴더의 MP4를 확인한다.


## 배경 3가지 · 오브제 4가지

형태가 생기고, 변하고, 이어지도록 아래 기법을 함께 사용한다.

### 배경: 공간이 서서히 만들어지는 방식

| 사용 기법 | 간단한 설명 |
| --- | --- |
| 기억 기반 반응·확산 | 작은 영역들이 이웃에 영향을 주며 퍼지고 연결된다. 원본 배경과 이전 장면의 흔적을 참고해 공간이 자란다. |
| 진화적 파라미터 탐색 | 퍼지는 속도와 사라지는 정도 등을 여러 조합으로 시험한다. 기억을 유지하면서 새로운 변화도 있는 조합을 고른다. |
| 다중 규모 패턴 경쟁 | 작은 무늬와 넓은 형태가 함께 자라고 경쟁한다. 일부는 약해져 사라지고, 남은 기억에서 다시 생긴다. |

### 오브제: 사물의 형태가 발달하는 방식

| 사용 기법 | 간단한 설명 |
| --- | --- |
| 기억 기반 형태 문법 | 원본 사물의 윤곽과 색을 참고한다. 점과 선, 작은 면이 생기며 책·손처럼 알아볼 수 있는 형태로 자란다. |
| 기하 구조 진화 | 사물의 모양을 조절하는 내부 연결점을 조금씩 바꾸거나 섞는다. 그 결과가 사물의 성장과 휘어짐에 반영된다. |
| 품질·다양성 선택 | 원래 사물의 특징을 유지하는지, 기존 형태와 다른지도 함께 살핀다. 한 가지 모양만 남지 않게 여러 형태를 보관한다. |
| 시간적 기억 상속 | 이전 사물의 색·형태·흔적 일부를 다음 장면에 넘긴다. 앞 장면의 기억이 다음 형태의 출발점이 된다. |

**Open-ended 적용:** 생성 중 여러 변화를 시험하고 선택하며 다음 상태로 이어 간다. 현재는 전달받은 이미지와 정해진 규칙 안에서 변화한다.

### 전체 작동 순서

입력을 읽는다 → 배경과 오브제를 각각 만든다 → 하나의 화면으로 합친다 → 일부 기억을 다음 장면에 넘긴다.

이야기는 등장 순서와 사건을, 감정·소리는 형성 속도와 흔들림을 조절한다. 관객 분위기도 숫자로 반영할 수 있으며, 현재는 직접 지정한다.


## 공통 규격과 파일 구조

현재 공유 자료에서 확인한 팀 간 전달 기준이다. 각 팀의 결과를 같은 장면에 연결할 때 아래 항목을 맞춘다.

| 항목 | 공통 전달 기준 |
| --- | --- |
| 장면·시간 | 기·승·전·결 4장면. 장면당 75초, 전체 300초. |
| 최종 영상 | 1920 × 1080 / 30 fps / MP4 |
| 배경 이미지 | 1920 × 1080 PNG. 글자 없는 배경판. |
| 오브제 이미지 | 512 × 512 PNG. 배경이 투명한 RGBA 형식. |
| 감정 | 기쁨·슬픔·분노·공포·놀람·혐오·중립의 7종.
2팀 이후 대표 감정 강도(intensity)는 0-1. |
| 장면 연결 | 1=기, 2=승, 3=전, 4=결.
JSON의 scene·act와 scene_01~04 파일을 맞춘다.
오브제 이름과 순서도 대본과 같게 한다. |
| 전달 파일 | dream_scenes.json: 이야기 / scenes.json: 배경 정보 / objects.json: 오브제 이름·파일 대응 |
| 사운드 | 전달받은 300초 음원. 영상과 같은 시간으로 재생. |
