# DreamModel 생성·진화 및 배경 셀룰러 오토마타 구현 명세

DreamModel은 4장면(기·승·전·결 각 75초, 총 300초)의 배경과 오브제를 각각 독립적인 생성·진화 과정으로 형성하고 하나의 세계 시계 위에서 결합한다.

---

## 1. 꿈 재현 — 배경 셀룰러 오토마타 & Open-Ended 진화 시스템

원본 심상 배경판(`scene_01~04.png`)과 시나리오별 고유 사운드를 직결하여 5분 배경 애니메이션을 생성하는 핵심 구현은 [`background_ca_engine.py`](../runtime/background_ca_engine.py), [`background_scene_decomposer.py`](../runtime/background_scene_decomposer.py), [`render_background_ca.py`](../tools/render_background_ca.py)에 수록되어 있다.

### ① 원본 배경판 4계층 물리 분해 (`extract_plate_layers`)
원본 배경판에 인위적 가짜 도형을 추가하지 않고, 다중 스케일 주파수 및 경사도 분해를 통해 4개의 물리 계층과 셀룰러 서식지(`hab`)를 추출한다.
- **`deep_bg` (심층 안개 여백)**: $\sigma=38.0$ 저주파 가우시안 분해 층 (차등 패럴랙스 배율 `0.35×`)
- **`mid_body` (중간 공간 몸체)**: $\sigma=4.2$ 중주파 대역에서 추출한 장소의 구조 골격 (패럴랙스 배율 `1.00×`)
- **`high_dots` (고휘도 점묘 입자)**: 원본에 새겨진 점묘 알갱이를 분리한 고주파 입자층 (역위상 패럴랙스 `-1.45× ~ -2.20×`)
- **`lines` (기억 윤곽 선화)**: Sobel 경사도와 DoG($\sigma=1.2 - \sigma=4.5$)를 결합해 추출한 원본 공간의 윤곽선

### ② 기억 셀룰러 오토마타 (`MemoryCA`) 및 도트 박리 상전이
$240 \times 135$ (`8px` 셀 단위) 격자에서 각 셀은 기억 활성(`M`), 에너지 자원(`E`), 지속 시간(`A`), 망각 상태(`ex`), 재기억 변위(`Dm`)를 매 프레임 갱신한다.
- **비동기 공간 에너지 위상**: 장면 중반의 전역 암전을 방지하기 위해 공간 좌표 $(u,v)$마다 서로 다른 에너지 초기 위상(`phase_f`)과 이동 충전 파동(`travel_wave`)을 부여한다.
- **도트 박리 (`M_dot`)**: 에너지가 고갈된 망각 셀(`ex > 0`)은 화면이 어두워지는 대신, 응집된 `mid_body`가 허물어지며 점묘 도트(`lat8`, `lat4`, `lat24`)와 윤곽 선화(`lines`)로 박리(Delamination)되어 부유한다:
  $$M_{\text{dot}} = \operatorname{clamp}(M + 0.58 \cdot \text{ex} \cdot \text{hab},\; 0,\; 1)$$
- **어긋난 재기억 (`Dm`)**: 망각에서 회복된 셀(`recovered`)은 감정 변이율(`mut`)에 비례한 가우시안 변위 벡터 $\Delta \mathbf{D}_m$만큼 이동한 위치에서 재발아한다.

### ③ 다중 스케일 점묘 격자(`Lattice`)의 크기 맥동과 선화(`lines`) 유지
- **3중 점묘 격자**: 주 도트(`8px`, `lat8`), 미세 입자(`4px`, `lat4`), 빛망울 보케(`24px`, `lat24`)로 구성된다.
- **도트 반지름 호흡**: 모든 도트 반지름은 고정되지 않고 셀룰러 활성도 $V_c$, 감정 호흡 `breath`, 사운드 중음역 `mid`, 타격음 `onset`에 의해 매 프레임 작았다 커졌다 맥동한다.
- **윤곽 선화 발현**: 원본 윤곽 선화(`lines`)는 셀룰러 발아 전선($\text{front} = 4M(1-M)$)과 망각 경계($\text{ex}$)에서 도트 사이를 꿰매듯 또렷하게 드러난다.

### ④ Open-Ended 변형장 진화 (`FieldEvolution`)
11.5초마다 18개의 연속 변형장 유전자 후보를 생성하고, **구조적 매끄러움과 연속성(Fitness, 54%)** + **과거 아카이브 대비 새로움(Novelty, 46%)** + **생존자 간 최소 거리 제약($d > 0.12$)**을 만족하는 상위 3개 엘리트 해를 선발·교차·돌연변이시켜 공간의 굴절과 원근을 비반복적으로 진화시킨다.

## 2. 영역 그래프 반응·확산 및 오브제 4대 기법

영역 그래프 기반 반응·확산은 [`background_openended.py`](../runtime/background_openended.py)에, 오브제의 구조 진화·선택·상속은 [`dream_world.py`](../runtime/dream_world.py) 및 [`dream_surfaces.py`](../runtime/dream_surfaces.py)에 구현되어 있다.

| 구분 | 기법 | 실제 규칙 및 구현 범위 |
| :--- | :--- | :--- |
| **배경 (영역 그래프)** | Memory-Conditioned Reaction-Diffusion | 불규칙 영역 인접 그래프에서 활성·억제 물질과 표면 물질량을 갱신하며 지역 기억을 형성한다. |
| **배경 (영역 그래프)** | Evolutionary Parameter Search | 3규모별 확산·활성·억제·침전·소멸 계수를 기억 적합도(.68) + 새로움(.20) + 다양성(.12)으로 진화 탐색한다. |
| **배경 (영역 그래프)** | Multi-scale Pattern Competition | 1/2/4단계 이웃 범위 패턴이 한정된 물질량과 순환 억제를 통해 경쟁하고 국소 소멸 후 재생한다. |
| **오브제** | Memory-Conditioned Visual Grammar | 실제 RGBA 윤곽·색·인접 관계에서 점·연결선·작은 면이 형성되고 표면으로 발달한다. |
| **오브제** | Geometric Organism Evolution | 2–7개 제어 노드의 수·위치·굽힘을 변이시키고 양친 제어 구조를 재조합·선발한다. |
| **오브제** | Quality-Diversity Selection | 소스 영역 중심과의 관계, 구조 안정성, 이야기 순위를 품질로 평가하고 형태 계열별 아카이브를 보존한다. |
| **오브제** | Temporal Memory Inheritance | 이전 표면의 색·출생점·이동 trace와 제어 구조를 다음 장면에 전달(이전 .35 + 새 구조 .65)한다. |
