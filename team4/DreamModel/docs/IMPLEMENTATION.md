# DreamModel 생성·진화 구현

DreamModel은 4장면의 배경과 오브제를 각각 다른 과정으로 형성하고, 하나의 300초 시간축에서 결합한다. 받은 이미지 전체를 완성된 레이어로 붙이는 대신 윤곽·영역색·인접 관계를 기억으로 추출한다.

## 배경의 3가지 기법

모두 [background_openended.py](../runtime/background_openended.py)에 구현되어 있다.

| 기법 | 실제 규칙 | 화면 / 조건 연결 |
|---|---|---|
| Memory-Conditioned Reaction-Diffusion | 불규칙 영역 인접 그래프에서 활성·억제 물질과 표면 물질량을 갱신한다. 배경의 색·명암·경계·구도와 이전 trace가 초기 상태와 지역 기억을 만든다. | 없는 공간에서 영역이 자라 연결된다. 이야기의 중요 영역은 성장 시작과 기억 적합도를, 감정·소리는 생성 조건을 바꾼다. |
| Evolutionary Parameter Search | 3규모별 확산·자기활성·억제·침전·소멸 계수를 유전자로 사용한다. 유지 후보 6개와 변이 자손 5개를 실제 상태에서 시험한다. 기억 적합도 .68 + 새로움 .20 + 규모 다양성 .12로 평가한다. | 관객 활성도에 따라 6–8초마다 탐색하고 선택 계수를 5초에 걸쳐 연결하여 갑작스러운 교체를 줄인다. |
| Multi-scale Pattern Competition | 1/2/4단계 이웃 범위의 패턴이 한정된 물질량과 순환 억제를 통해 경쟁한다. 비중 .24 미만·물질량 .15 미만·감소율 .0015/s 초과가 4초 지속되면 국소 패턴을 제거한다. 이후 기억에서 재생한다. | 작은 구조와 넓은 공간 구조가 성장·약화·재생한다. 형성 뒤 연결된 공간의 밀도와 곡률이 달라진다. |

반응·확산은 [Turing의 형태 발생 논문](https://fab.cba.mit.edu/classes/862.19/notes/computation/Turing-1952.pdf)의 국소 반응과 서로 다른 확산 원리를 참고한다. 현재 식은 공간 식별을 위한 예술적 활성·억제 모델이다. 정확한 Gray-Scott 방정식이나 Turing 불안정성을 검증했다고 주장하지 않는다.

## 오브제의 4가지 기법

구조 진화·선택·상속은 [dream_world.py](../runtime/dream_world.py), 가시 형태 문법은 [dream_surfaces.py](../runtime/dream_surfaces.py)에 구현되어 있다.

| 기법 | 실제 규칙 | 구현 범위 |
|---|---|---|
| Memory-Conditioned Visual Grammar | 실제 RGBA 윤곽·색·인접 관계에서 점·연결선·작은 면이 형성되고 표면으로 발달한다. | 초기 빈 프레임과 영역별 성장, 이야기 순위에 따른 출현을 구현했다. |
| Geometric Organism Evolution | 2–7개 제어 노드의 수·위치·굽힘을 변이시키고 양친 제어 구조를 재조합·선발한다. 선택 구조는 가시 표면에 부드럽게 반영된다. | 내부 구조의 진화·재조합과 부분 면의 성장·쇠퇴를 구현했다. 완성 물체 간 물리적 충돌·융합은 미구현이다. |
| Quality-Diversity Selection | 소스 영역 중심과의 관계, 구조 안정성, 이야기 순위를 품질로 평가하고 과거 특징 거리와 형태 계열별 아카이브를 사용한다. | selection/novelty/diversity를 제거한 실행에서 선택과 실제 프레임 차이를 확인했다. selection off에서도 아카이브 내부 품질 교체는 유지한다. |
| Temporal Memory Inheritance | 이전 표면의 색·출생점·실제 이동 trace와 제어 구조를 다음 장면에 전달한다. 다른 역할 간 상속은 이전 구조 .35 + 새 구조 .65로 재조합한다. | 항해일지→서류철, 그림자→손 등 부모 ID와 구조 특성을 상속한다. memory off 비교에서는 전환 이후 상태와 프레임이 달라진다. |

품질·다양성 보존은 [MAP-Elites](https://arxiv.org/abs/1504.04909)의 특징 공간별 보존 원리를 참고한다. 점수는 기억·형태의 대리 지표이며 관객의 식별률을 측정한 값이 아니다.

## 공통 조건과 통합

- Story: 중요 기억 영역, 오브제 출현 순서, 공간과 사건의 시간 배치.
- Emotion: 생성 안정성, 변이·성장·쇠퇴 조건. 색 하나로 감정을 표시하지 않는다.
- Collective Affect: 활성도·긴장도·일치도를 생성 조건으로 사용한다. 실측 미제공 기본값은 SIMULATION이다.
- Sound: 제공 음원의 에너지와 증가량을 평활하여 성장·탐색·변형의 시간적 조건으로 사용한다. 원본 소리는 같은 시계로 최종 MP4에 포함한다.

배경과 오브제는 같은 세계 시계와 재질 렌더를 공유한다. 영역별 성장과 소멸, 색·형태·경로 상속으로 다음 장면을 형성한다. 초기 선 흔적에도 발달한 표면과 같은 소멸 곡선을 적용한다.

## 검증과 한계

[validate_conditions.py](../tools/validate_conditions.py)는 같은 입력과 seed에서 조건별 제거 비교와 재실행 재현성을 확인한다. 기존 10Hz 비교에서는 story/emotion/sound/collective 각각이 배경과 오브제 양쪽의 픽셀에 영향을 주었다. 배경 진화·경쟁 제거도 배경 결과를 바꿨으며, 국소 소멸·기억 재생 사건을 기록했다. 비교용 시뮬레이션 주기와 전달 영상의 30fps는 구분한다.

[tests](../tests)는 입력 계약, 구조·선택·기억, 초기 형성, 장면 경계의 직렬화 상태 복원, 최종 소멸과 영상 출력을 검사한다. 완성본 제작에서는 1920×1080·30fps·9,000프레임·300초 전체 디코딩과 원본 음원 동기를 별도로 확인했다.

오브제 배치는 ASSUMPTION이며, 실제 관객 집단 자료가 없어 SIMULATION을 사용한다. 전달 자산과 제한된 문법을 사용하는 탐색으로, 무한한 새 개념의 발견이나 관객 실험 성공을 입증한 결과는 아니다. 가시성·자연스러움은 별도 시각 검수 대상이다.
