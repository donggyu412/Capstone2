# 3팀 오브제 PNG (GridModel 입력용 · 2026-10-07)

3팀 오브제(시스템 II)의 **최종 투명 PNG** 13장입니다. `../storyboard/` 의 `dream_scenes.json` 과 같은 대본으로 만들었습니다.

| 파일 | 내용 |
|---|---|
| `scene_01~04/obj_<순번>_<오브제이름>.png` | 장면별 오브제 · **512×512 · 투명 배경(RGBA)** |
| `objects.json` | 장면 · 순번 · 오브제 이름 · 파일 경로 대응표 |

## 장면별 구성 (총 13장)

| 장면 | 장수 | 오브제 |
|---|---|---|
| scene_01 (기) | 3 | 낡은 항해일지 · 푸른빛 냉동액 웅덩이 · 팔이 긴 부유하는 그림자 |
| scene_02 (승) | 3 | 떨어지는 물방울 · 낡은 서류철과 종이 · 팔이 길게 늘어진 그림자 형상 |
| scene_03 (전) | 4 | 서류철 · 무게가 변하는 종이 · 팔이 늘어진 형상 · 벌어지는 타일 금 |
| scene_04 (결) | 3 | 밤색 서류철 · 금이 간 타일 바닥 · 창백하고 얇은 손 |

## 규칙

- `scene_0N` 은 `dream_scenes.json` 의 `scene: N` 과 같은 장면입니다.
- 파일 이름의 `<순번>` 은 그 장면 `objects` 배열 안의 순서(1부터)이고, `<오브제이름>` 은 배열 속 이름의 띄어쓰기를 `_` 로 바꾼 것입니다.
  - 예: 장면 4 `objects[0]` = "밤색 서류철" → `scene_04/obj_1_밤색_서류철.png`
- 생성: ComfyUI · dreamshaper_8 + 3팀 LoRA(`dream_object_lora`, 10에포크, 세기 0.6)
- 배경 제거: rembg 4개 모델(u2net · isnet-general-use · birefnet-general · bria-rmbg) 결과를 비교해 장마다 수동 선택

## 참고

- 크기가 512×512 라서 1920×1080 배경판 위에 얹을 때는 키워서 쓰게 됩니다. 테두리가 부드럽게 잘려 있어 1.5~2배 정도까지는 무난합니다.
- `scene_01/obj_3`(그림자) 처럼 검은 오브제는 어두운 배경판 위에서 잘 안 보일 수 있습니다. 3팀 오브제 엔진은 차가운 테두리 빛을 얹어 처리했습니다.
- `scene_04/obj_2`(타일 바닥)는 가운데 흰 면이 배경색과 거의 같아 투명으로 잘려 있습니다(파란 테두리와 선만 남음).
- 원본 저장소: `team3-object` 브랜치 `output_objects/` (PNG 커밋 `8183fb9`)
