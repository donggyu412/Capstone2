| 파일 | 내용 |
|---|---|
| `scene_01~04.png` | 장면 1~4(기·승·전·결) 배경판 · **1920×1080** · 글자·표지 없음 |
| `scenes.json` | 장면별 정보(막 · 제목 · 감정 · 배경 설명 · 참조 작가 · 캡처 시점) |

- 오브제 PNG 는 `../objects/` 에 이어서 올릴 예정입니다.
