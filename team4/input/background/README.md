# 꿈 재현 — 배경 구현 전달 자료 (`team4/input/background/`)

본 폴더는 **꿈 재현 — 배경 애니메이션 시스템(Cellular Automata × Open-Ended Evolution)**에서 생성한 **1·2·3번 시나리오별 5분 배경 영상 3종**을 오브제 합성 모듈에 전달하기 위해 구성된 전용 입력 슬롯입니다.

> 기존 공통 입력 폴더(`team4/input/objects/`, `team4/input/storyboard/`)는 변경하지 않고 그대로 보존하며, 오브제 합성에 필요한 배경 애니메이션 3종만 본 `team4/input/background/` 폴더에 수록되어 있습니다.

## 1. 수록된 배경 애니메이션 영상 3종 (오브제 합성 전달용)

모든 영상은 **공통 마스터 규격(`1920×1080`, `30.0 fps`, `300.0초`, 정확히 `9,000 프레임`, 시나리오별 고유 사운드 `AAC 48kHz 192kbps` 포함)**으로 제작되었습니다.

| 파일명 | 시나리오 식별자 | 4막 감정 흐름 (기→승→전→결) | 규격 및 시간축 | 고유 사운드 |
| :--- | :--- | :---: | :--- | :--- |
| **`1번_꿈재현_배경_사운드.mp4`** | `1_놀람공포중립공포` | 놀람 → 공포 → 중립 → 공포 | `1920×1080` · `30fps` · `300.0s` (`9,000f`)<br/>기(`0~75s`) · 승(`75~150s`) · 전(`150~225s`, 클라이맥스 `195s`) · 결(`225~300s`) | 1번 고유 사운드 결합 완료 |
| **`2번_꿈재현_배경_사운드.mp4`** | `2_혐오공포기쁨슬픔` | 혐오 → 공포 → 기쁨 → 슬픔 | `1920×1080` · `30fps` · `300.0s` (`9,000f`)<br/>기(`0~75s`) · 승(`75~150s`) · 전(`150~225s`, 클라이맥스 `195s`) · 결(`225~300s`) | 2번 고유 사운드 결합 완료 |

- **GitHub 원격 저장소 직접 수록본**: 위 3개 MP4 파일은 GitHub 단일 파일 업로드 제한(`100MB`)을 통과하도록 해상도(`1920×1080`), 프레임수(`9,000f`), 러닝타임(`300.0s`), 오디오(`AAC 192kbps`) 손실 없이 편당 약 `66MB`로 맞춘 Git 배포본입니다.
- **초고비트레이트 마스터본 (`0.653 GB` / 편)**: `17.2 Mbps CBR`로 인코딩된 `0.653 GB`(`652.9 MB`) 마스터 MP4 3종은 `python -m team4.DreamModel.tools.render_background_ca --films 1,2,3` 실행 시 `team4/DreamModel/output/`에 동일하게 생성됩니다.
- **시나리오별 원본 배경판 및 서사 JSON**: `team4/DreamModel/configs/scenarios/` 하위에 `1_놀람공포중립공포`, `2_혐오공포기쁨슬픔`, `3_공포공포중립중립` 3개 시나리오 세트가 수록되어 있습니다.
