# 꿈 사운드 생성기 — 3팀 · 사운드

2팀 스토리보드 + 3팀 배경 사진 + 오브제 그림을 읽어, **장면마다 그 이야기와 그림에 맞는 창발적 사운드**를 만든다.
- 장면 길이 **75초 고정** (4장면 = 5분) · 처음 보는 스토리보드도 **3분 안에**
- 출력 **WAV 48kHz** · 해설 자료(어떤 소리가 몇 초에, 이야기의 어느 문장·그림의 무엇 때문에)
- 소리는 **전부 자체 합성** — 외부 음원·생성 모델 출력 0개 → 상업 이용 제약 없음 (`LICENSE_AUDIT.md`)

## 네 단계

```
1 읽기  read.py     ① 이야기 문장 → 소리가 날 시각      문장이 글의 어디쯤인가 = 장면 안의 시각
                    ② 그림 수치   → 음색                배경 밝기·암부 → 공간·룸톤 / 오브제 실루엣 → 울림
                    ③ 그림 인식   → 무슨 소리 (vision.py) 배경에 보이는 형광등·창문·시계… 와 그 위치·거리
                                                         오브제가 무엇인지(책 → 종이 넘김) · 재질 · 장소
2 재료  pieces.py   위 소리들을 1~5초 짧은 조각으로 새로 합성 (synth.py) — 사건 · 낱말 · 오브제 · 그림 속 소리원
3 진화  evolve.py   조각을 어떻게 배치·혼합할지 수백 번 바꿔 들어 보고 가장 듣기 좋은 구성을 고름
                    듣기 좋은 정도 = 잡음 적음 · 날카롭지 않음 · 탁하지 않음 · 떨림 없음 · 붐비지 않음 ·
                                     층 균형 · 사건이 들림 · 그림 부합
4 렌더  render.py   고른 구성으로 75초 배치 → 배경 분위기에 맞춘 작곡(composition.py) → 꿈의 변형(dreamfx.py) → 공간
```

```
team3/
├─ background/input/storyboard/   dream_scenes.json · scene_01~04.png   ← 읽기만
├─ object/                         output_objects/ 또는 dataset/10_dream_object/   ← 읽기만
└─ sound/                          ← 여기
   ├─ generate_sound.py            실행 파일 (네 단계를 순서대로)
   ├─ eval_lengths.py              길이 불변성 실험 (논문용)
   ├─ dreamsound/                  read · vision · pieces · synth · evolve · render · composition · dreamfx · style · guide · provenance · timing
   ├─ PROCESS.md                   꿈 사운드 제작 과정 — 네 단계를 예시·공식과 함께 (발표·보고서용)
   ├─ LICENSE_AUDIT.md             저작권 · 라이선스 검토서
   ├─ PAPERS.md                    단계별 논문 근거 — 차용 · 보완 · 차이
   └─ output/                      가장 최근 결과가 바로 여기 — 새로 만들면 바뀜 (깃에 안 올라감)
```

## 1. 설치
```
pip install -r team3/sound/requirements.txt          ← 이것만으로도 돈다 (그림 인식 없이)
```
그림 인식(1단계 ③)까지 쓰려면 — GPU 본체 권장, 노트북 CPU 도 됨:
```
pip install torch --index-url https://download.pytorch.org/whl/cu130     ← 본체 CUDA 에 맞게 (노트북은 pip install torch)
pip install -r team3/sound/requirements-gpu.txt
```
처음 실행할 때 모델을 한 번 내려받는다(약 2.5GB · 로그인 필요 없음). 결과는 `cache/vision/` 에 남아 같은 그림은 다음부터 0초.

## 2. 실행 (저장소 루트에서)
```
python team3/sound/generate_sound.py
```
화면에 `[1] 읽기 → [2] 재료 · [3] 진화 → [4] 렌더` 순서로 나오고, 마지막에 단계별 시간과 결과 폴더가 나온다.

**영상이 나오면 붙이기** (몇 초 · 소리는 다시 만들지 않는다)
```
python team3/sound/generate_sound.py --mux <영상.mp4>
```

| 옵션 | 뜻 |
|---|---|
| `--style apichatpong` | 사운드 스타일 — 입력·출력은 같고 재료·진화·렌더의 규칙만 바뀐다 (5절) · `apichatpong_deep` = 더 진하게(음악 없음) · 기본 `default` |
| `--vision auto` | 그림 인식 — auto(기본): torch·transformers 가 있으면 사용 · `on`: 꼭 사용(안 되면 멈춤) · `off`: 안 씀 |
| `--scenes <json>` | 다른 스토리보드로 (기본: 배경 폴더의 가장 최근 json) |
| `--seed 3` | 다른 시드 = 다른 조각·다른 변형 (같은 시드 = 같은 결과) |
| `--out <폴더>` | 결과를 다른 폴더에 (기본 `team3/sound/output/` — 이전 결과를 바꿈) |
| `--time-budget 170` | 전체 목표 시간(초). 진화가 이 안에 끝나게 스스로 멈춘다. `0` = 제한 없음 |
| `--mp3` | 미리듣기용 mp3 도 함께 |
| `--install` | `scene_NN.wav` 를 배경 엔진 입력 폴더에도 복사 |

## 4. 무엇이 무엇을 정하나

| 입력 | 단계 | 소리로 |
|---|---|---|
| 이야기 문장 | 1 ① | 사건(물방울·종이·균열·전기 험…)과 **그 문장 자리 = 장면 안 시각** · ✎ 낱말 소리 — 사건표에 없는 낱말도 소리로(손 → 손 스침, 글씨 → 펜촉, 가슴 → 박동, 벽·타일 → 두드림, 먼지 → 사각임, 소매 → 천 스침) · 꿈의 물리 법칙(빨라지는 간격·삼켜지는 소리·원인보다 먼저 오는 소리…) · 정적 문장 → 그 자리를 비움 |
| 배경 사진 수치 | 1 ② | 밝기 → 소리의 밝기 · 암부 → 저역 · 윤곽 → 룸톤 결 · 깊이 → 잔향 |
| 오브제 실루엣 | 1 ② | 클수록 낮게 · 밝을수록 높게 · 각질수록 날카롭고 비조화 · 대칭일수록 조화 (모달 합성) |
| 👁 배경 그림 인식 | 1 ③ | 보이는 소리원(형광등 → 전기 험, 창문 → 유리, 시계 → 째깍)이 **그림 속 좌우 위치에서, 멀수록 작고 먹먹하게** · 장소(복도·서가·동굴…) → 잔향 · 보이는 재질 → 꿈의 변형의 음색 |
| 👁 오브제 그림 인식 | 1 ③ | 정체 소리(항해일지 → 종이 넘김, 냉동액 → 액체)가 그 오브제가 나오는 문장 자리에서 · 재질 → 울림의 성격(종이는 짧게, 금속은 길고 비조화롭게) |
| 배경 분위기 | 4 | 밝기·색온도·채도·대비 + 장소 (65%) + 이야기 감정 (35%) → 선법(공포 = 프리지아 …)·화성·동기 빠르기 |
| 꿈의 변형 | 4 | 이질적 침입 26종(어두운 장면엔 밝은 소리 14종 — 오르골·하프·피리·실로폰·칼림바·자전거 벨·아이 웃음·태엽 장난감… / 밝은 장면엔 어두운 소리 12종 — 으르렁·뱃고동·사이렌·천둥·발소리·징·열리는 문·속삭임…) · 음색 치환(이야기에 없는 생물 16종 — 새·개구리·고양이·고래·부엉이·개·늑대·벌·갈매기·돌고래·매미·뻐꾸기… — 의 몸짓 × 장면 재질) · 변신 · 데자뷔. 이야기에 이미 나온 소리는 빼고, 장면마다 다른 것이 돌아가며 나온다 |

## 5. 사운드 스타일 (`--style`, `dreamsound/style.py`)

```
python team3/sound/generate_sound.py --style apichatpong
```

아피찻퐁 위라세타꾼 영화의 사운드 방식 — 사운드 디자이너 Akritchalerm Kalayanamitr 인터뷰(MUBI, 2022)에서 뽑은 원칙: "주변 소리로 이야기를 한다" · 벌레·새·공기·웅웅거림을 층으로 · 평평한 음량 · 짧은 완전한 침묵 · 소리의 반복과 변형 · 〈메모리아〉의 굉음. 영화 소리를 쓰지 않고 수식으로 합성하므로 저작권 판정은 그대로다 (PAPERS.md §12).

| 단계 | 기본 (`default`) | 아피찻퐁 스타일 (`apichatpong`) |
|---|---|---|
| 1 읽기 | — | 그대로 |
| 2 재료 | 룸톤 + 사건 + 낱말 + 오브제 | 그대로 — 새 조각을 만들지 않는다. 대신 렌더가 **이 장면의 조각으로 주변 소리 층을 짠다**: 반짝이는 결(짧은 사건 조각을 2옥타브 올려 촘촘하게 → 좁은 공명 몇 개로 벌레처럼 떨게) · 공기의 결(숨·냉기·천·종이 조각을 길게 늘여 일렁이게) · 낮은 웅웅거림(오브제 문지름을 2옥타브 내려 저역만) · 소리 시퀀스의 재료 = 장면의 전기 험 등 기계음, 없으면 첫 오브제 울림 |
| 3 진화 | 사건이 바닥보다 4~14dB 위 · 초당 0.4~1.8개 · 바닥이 가장 크면 감점 | 사건이 주변 소리와 비슷한 크기(−3~+3dB) · 초당 **0.12~0.55개**(10-26 느리게, 이전 0.2~0.8) · 바닥이 가장 커도 됨 · **음량 고름**(다이내믹스가 작을수록) 항목 추가(10%) · 출발점: 바닥 크게 · 사건·오브제 적게 · 폭 넓게 · 잔향 조금 덜 · **쓰는 값의 범위**: 바닥 음량 0.6 이상 · 사건 빈도 0.4 이하 · 오브제 울림 10초당 0.5번 이하 |
| 4 작곡 | 화성 패드 · 5음 동기 · 배경 지속음 | 모두 끄고 장면마다 한 번 **먼 라디오**(작은 스피커 같은 대역 · 살짝 찌그러짐 · 잡음 — 선율은 같은 5음 동기) |
| 4 꿈의 변형 | 이질적 침입 · 음색 치환 · 변신 · 데자뷔 | **침묵의 틈**(잔향까지 2~4초 완전히 멈췄다 돌아옴 · 1~2번) · **깊은 쿵**(꿈 전체에 한 번 — 전 장면) · **소리 시퀀스**(기계음이 리듬처럼 되풀이되며 낮고 먹먹해짐) · 변신 · 데자뷔 |
| 4 주변 소리 층 | — | 공간·잔향(막의 먹먹함)을 거치지 않아 또렷하게 · 장면 경계에서 **8초** 겹쳐 끊기지 않게 이음 (효과음 경계는 그대로 2.8초) |
| 4 정령 | '존재감' 소리 | 그림자·형상이 나오는 문장에서도 소리를 내지 않음 (해설에 "○ 정령은 소리 없이"로 기록) |
| 4 곡선 | 기승전결 음량 곡선 | 15%만 남겨 거의 평평 · 결 장면 끝 25%만 천천히 낮춤 |
| 4 박 · 결 (10-26) | 층화 표집(고르게 흩음) · 같은 조각 되풀이 · 사인파 일렁임 | **느리고 불규칙하게 · 자연스럽게**: 사건 간격 = 감마 분포(모양 0.6 — 몰렸다 오래 빔) · 문장 자리 닻을 0.1~1.2초 뒤 무작위로 · 소리마다 음높이(±0.3반음) · 크기(4dB) · 거리(35%는 멀리서 먹먹하게)가 다름 · 바로 앞과 같은 조각 피함 · 낱말 소리는 낱말마다 2번까지 · 알갱이 밀도 · 바람 · 벌레 울음이 주기 없는 1/f 잡음으로 출렁이고 벌레는 가끔 몇 초 멈춤 · 소리 시퀀스 1.35배 느리게 ±15% 흔들림 · 먼 라디오 박 0.52초 + 루바토 ±8% |
| 출력 | — | 같은 파일 · 해설 자료 첫머리에 스타일 카드 |

**비교용 — `--style apichatpong_synth`**: 주변 소리를 장면과 무관하게 따로 합성한 밤 숲 소리(밤벌레 · 바람과 잎 · 웅웅거림 · 선풍기/형광등)로 (10-16 첫 판 방식).

**더 진하게 — `--style apichatpong_deep`**: 위와 같고, 먼 라디오도 빼서 음악을 완전히 없애고(근거 자료에 더 가깝게), 소리 시퀀스를 28초로 · 침묵의 틈을 장면마다 2번으로 늘린다.

## 6. 알아 둘 것
- **그림 인식이 없으면** (torch 미설치·다운로드 실패) 1단계 ③만 건너뛴다. 오브제 정체 소리는 오브제 팀 영어 이름표(`OBJ_ENGLISH_MAP`)로 대신 정한다. 해설 자료 첫머리에 사용 여부가 적힌다.
- **오브제 이미지**: `team3/object/output_objects/scene_N/` 이 있으면 그걸, 없으면 `dataset/10_dream_object/` 의 캡션으로 장면을 거꾸로 찾는다. `prepare_dataset.py` 는 '밤색 서류철' 그림에도 '서류철' 캡션을 단다 — 사운드 쪽은 처리하지만, 오브제 팀 LoRA 학습 캡션에도 같은 문제가 있다.
- **시간**: 2코어 클라우드 컨테이너에서 약 165초(그림 인식 없음). 코어가 많으면 같은 시간 안에 더 많이 탐색한다.
- **길이 불변성 실험**: `python team3/sound/eval_lengths.py` (output/ 의 결과로 · PAPERS.md §9).
