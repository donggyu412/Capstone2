# 저작권 · 라이선스 검토서 — 꿈 사운드 생성기 (3팀 · 사운드)

> 목적: 이 생성기가 만든 소리를 **상업적으로 써도 되는지**, 그리고 **제3자 저작권이 섞이지 않았는지**를 근거와 함께 남긴다.
> 실행마다 `output/provenance.json` 에 같은 판정과 증거(조각 출처 · 그림 인식 모델 · 코드/입력 지문)가 자동으로 기록된다.
> ⚠ 이 문서는 공개된 라이선스·기관 자료를 정리한 기술 검토이며 법률 자문이 아니다. 실제 상업화(판매·계약) 전에는 학교 산학협력단이나 전문가 확인을 권한다.
> 작성 2026-10-07 · 4단계 구조로 고침 2026-10-08.

---

## 1. 결론

| 항목 | 내용 |
|---|---|
| 출력 소리의 출처 | 이 저장소의 코드가 수식으로 계산한 합성음뿐 — **외부 음원 0개, 생성 AI 모델 출력 0개** |
| 제3자 저작권 | **섞일 경로가 없음** |
| 상업 이용 | **제약 없음** |
| 그림 인식 모델 (1단계 ③, 10-08) | 그림을 *읽기만* 하고 소리를 만들지 않는다. 쓰는 세 모델 모두 상업 이용이 허용되는 라이선스(Apache-2.0 · MIT) |

10-08 부터 생성 모델 재료(Stable Audio Open)·CLAP·ImageBind 선택 기능을 뺐다. 그래서 판정이 '자체 합성' 하나다.

"저작권이 없다"는 말은 두 가지로 나뉜다.
1. **남의 저작권을 침해하지 않는가** → 외부 음원도, 남이 학습시킨 생성 모델의 오디오 출력도 쓰지 않는다. 침해가 생길 재료가 처음부터 없다(§2).
2. **이 결과물에 우리 저작권이 생기는가** → 한국저작권위원회는 사람의 창작적 기여 없이 기계가 만든 산출물은 보호하지 않는다(§4). 보호 여부와 상관없이 **우리가 상업적으로 쓰는 데는 지장이 없다.**

## 2. 구성 요소별 검토

|---|---|---|---|
| `team3/sound/` 코드 | 읽기 · 조각 합성 · 진화 · 작곡(기존 곡 없이 규칙으로) · 꿈의 변형(오르골·새소리 등도 수식으로) · 렌더 | 3팀 작성 (팀 소유) | 소리를 **계산**한다 — 결과물의 유일한 출처 |
| numpy · scipy | 수치 연산 · 필터 · FFT | BSD-3-Clause | 아니오 (계산 도구) |
| Pillow | 이미지 읽기 | MIT-CMU (HPND) | 아니오 |
| imageio-ffmpeg / ffmpeg | (선택) mp3 미리듣기 · 영상에 소리 붙이기 — WAV 는 scipy 가 직접 쓴다 | BSD-2 / LGPL·GPL 실행 파일 | 아니오 — 인코더 도구로 실행만. 도구의 라이선스는 결과물에 상속되지 않는다 |
| **SigLIP 2** (`google/siglip2-base-patch16-224`) | 그림의 재질·장소 분류 | **Apache-2.0** (모델 카드, 10-08 확인) | 아니오 — 확률 숫자만 낸다 |
| **Florence-2** (`florence-community/Florence-2-base`, Microsoft 공식 가중치의 transformers 변환판) | 그림 속 물체 찾기 · 설명 문장 | **MIT** (모델 카드, 10-08 확인) | 아니오 — 물체 이름·위치만 낸다 |
| **Depth Anything V2 Small** (`depth-anything/Depth-Anything-V2-Small-hf`) | 배경 깊이 | **Apache-2.0 — Small 만**. Base/Large/Giant 는 CC-BY-NC-4.0(비상업)이라 쓰지 않는다 | 아니오 — 깊이 숫자만 낸다 |
| torch · transformers | 위 모델 실행 | BSD-3-Clause · Apache-2.0 | 아니오 |
| 스토리보드 (2팀 · Claude API) | 시각·사건을 정하는 **입력 글** | Anthropic 상업 약관상 API 출력은 이용자(2팀) 소유 — 2팀 확인 권장 | 아니오 — 글을 읽어 수치로만 쓴다 |
| 배경 사진 · 오브제 그림 | 음색·공간·소리원을 정하는 **입력 이미지** | 각 생성 서비스·모델 약관 (오브제: DreamShaper 8, CreativeML OpenRAIL-M) | 아니오 — 수치·이름·위치만 뽑는다. 픽셀이 소리로 복사되지 않는다 |

**검토 후 제외한 모델 (10-08)** — 그림·영상에서 소리를 직접 만드는 공개 모델은 상업 이용이 막혀 있다.

| 모델 | 이유 |
|---|---|
| MMAudio | 코드는 MIT 지만 **가중치가 CC-BY-NC 4.0** |
| ThinkSound | GitHub 안내에 "연구·교육용, 상업 이용 불가" · 포함된 Stable Audio VAE 도 Stability AI 허락 필요 |
| HunyuanVideo-Foley | 라이선스가 **"유럽연합·영국·대한민국에는 적용되지 않음"** |
| ImageBind | CC-BY-NC 4.0 |

**코드 경로 확인:** 오디오 파일을 읽는 함수는 `pieces.load` 하나뿐이고, 같은 실행이 만든 조각 폴더(`output/_building/pieces/` → 끝나면 `output/pieces/`)만 읽는다. 외부 음원 폴더를 읽는 옵션이 없다. 실행마다 `provenance.json` 의 `pieces` 에 조각 하나하나의 출처(`procedural` + 합성 함수 이름 + 시드)가 남고, `external_audio_files` 는 0 이어야 한다. 그림 인식을 썼다면 `vision` 에 모델 이름·라이선스가 남는다.

**재현으로 검증:** `code_sha256`(코드 지문) · `inputs_sha256`(입력 지문)이 같고 같은 `--seed` 면 조각은 같은 소리가 다시 나온다. 그림 인식 결과는 `cache/vision/` 에 그림 지문별로 남는다. 진화가 시간 예산으로 일찍 멈췄다면 `report.json` 의 장면별 평가 횟수를 `--iters` 로, `--time-budget 0` 으로 실행하면 같은 소리가 나온다.

## 3. 왜 '자체 합성'인가

- **입증 가능성**: "출력의 모든 표본이 우리 코드의 수식으로 계산됐다"는 한 문장과 재현 실행으로 끝난다.
- **조건 없음**: 매출 기준, 이용 정책 같은 외부 조건이 붙지 않는다.
- **속도**: 생성 모델이 없어 처음 보는 스토리보드도 3분 안에 끝난다.
- **그림 이해는 따로**: 그림이 무엇인지는 상업 이용 가능한 인식 모델로 읽고, 소리는 그 결과에 맞춰 합성한다 — 생성 모델 없이도 "형광등이 보이면 전기 험", "책이면 종이 넘김"이 된다.

## 4. 한국 저작권 기준 — AI·기계 산출물

- 저작권법상 저작물은 "인간의 사상 또는 감정을 표현한 창작물"이다(저작권법 제2조 제1호).
- 한국저작권위원회: 사람의 창작적 기여 없이 AI 만으로 만든 것은 저작물이 아닌 '산출물'로 보고 보호하지 않으며, 사람이 창작적으로 기여한 부분에 한해 보호한다(위원장 인터뷰, 2026-04-21 · 문화체육관광부·한국저작권위원회 「생성형 AI 저작권 안내서」 2023-12 의 기조와 같음).
- 이 생성기는 학습된 생성 AI 가 아니라 사람이 설계한 규칙·수식·탐색 알고리즘으로 소리를 계산한다. 설계(어떤 이미지 특징을 어떤 음향으로 옮길지, 꿈의 법칙을 어떻게 소리로 옮길지, 기승전결 곡선)는 사람의 창작적 결정이다. 개별 소리의 저작물성은 사안별 판단이지만, **어느 쪽이든 우리가 상업적으로 쓰는 데 걸림돌은 없다.**

## 5. 함께 쓸 때 주의

- **최종 영상**: 사운드는 위와 같이 깨끗해도, 같이 쓰는 배경 사진(ChatGPT 등)·오브제 그림(DreamShaper 8)·스토리보드(Claude API)는 각 서비스·모델 약관을 따른다. 영상 전체를 상업적으로 쓰려면 각 팀이 자기 입력의 약관을 확인해야 한다.
- **1팀 사운드·내레이션**: 이 생성기는 1팀 녹음을 쓰지 않는다. 1팀 소리를 섞으면 그 소리의 출처(예: Gemini 생성 일상 소리)의 약관이 추가로 붙는다.
- **그림 인식 모델을 바꿀 때**: `SOUND_SIGLIP_MODEL` 등 환경 변수로 다른 모델을 쓸 수 있지만, 상업 이용이 허용되는 라이선스인지 먼저 확인한다(Depth Anything V2 는 Small 만).
