# 꿈 사운드 제작 과정 — 네 단계

캡스톤디자인2 · 3팀 사운드 · `team3/sound/generate_sound.py` · 2026-10-08
장면당 75초 고정 · 4장면 = 5분 · 처음 보는 스토리보드도 3분 안 (측정 164초) · WAV 48kHz · 소리 전부 자체 합성 · 외부 음원 0 · 상업 이용 제약 없음

> 코드 설명서는 [README.md](README.md), 단계별 논문 근거는 [PAPERS.md](PAPERS.md), 저작권 검토는 [LICENSE_AUDIT.md](LICENSE_AUDIT.md).

## 한눈에 보기 — 네 단계

2팀 스토리보드(글) · 3팀 배경 사진 · 오브제 그림을 읽어, **장면마다 그 이야기와 그림에 맞는 소리**를 만듭니다. 단계마다 코드 파일이 하나씩입니다.

| 단계 | 파일 | 하는 일 |
|---|---|---|
| **1 읽기** | `read.py` · `vision.py` | ① 이야기 문장 → **언제** · ② 그림 수치 → **어떤 음색** · ③ 그림 인식 → **무슨 소리** |
| **2 재료** | `pieces.py` · `synth.py` | 1~5초 짧은 소리 조각을 수식으로 새로 합성 (장면당 40여 개) |
| **3 진화** | `evolve.py` | 조각의 배치·혼합을 수백 번 바꿔 들어 보고 **가장 듣기 좋은 구성** 선택 |
| **4 렌더** | `render.py` | 75초로 배치 → **배경 분위기에 맞춘 작곡** → **꿈의 변형** → 공간 |

```text
스토리보드 + 배경 사진 + 오브제 그림
  → 1 읽기 → 2 재료 → 3 진화 → 4 렌더
  → team3/sound/output/  (dream_sound.wav · scene_01~04.wav · sound_guide.html · cue_sheet.csv · provenance.json)
```

### 세 입력이 맡는 역할

| 입력 | 정하는 것 | 예 (장면 1 · 물방울 떨어지는 천장과 젖은 바닥) |
|---|---|---|
| 이야기 문장 | **언제** 어떤 사건이 | "천장에서 물방울이 떨어진다." → 0:00.9 물방울 · "물방울 소리가 점점 빨라진다." → 끝으로 갈수록 촘촘 |
| 그림의 수치 | **어떤 음색**으로 | 배경 밝기 0.18·암부 55% → 낮고 어두운 공기 · 항해일지 실루엣(면적 0.65·대칭 0.98) → 조화로운 낮은 울림 |
| 그림 인식 | **무슨 소리**가 더 | 항해일지 = 책 → 종이 넘김이 "항해일지" 문장 자리에서 · 냉동액 웅덩이 → 액체 소리 · 배경에 형광등이 보이면 그 자리(좌우)에서 전기 험 |

> 💡 **원칙** — 모델은 그림을 *읽기만* 하고, 소리는 우리 코드가 *수식으로 만든다*. 그래서 모든 소리에 "어느 문장 · 그림의 무엇 때문"이라는 근거가 남고, 저작권 문제가 생길 재료가 없다.

## 1. 읽기 ① 이야기 → 언제

문장이 글 전체의 어디쯤에 있는지(0~1)를 장면 안의 시각으로 씁니다. 75초 장면에서 글의 40% 지점 문장 = 30초 근처. 문장 안의 **동작·재질 낱말**로 사건 종류를 찾습니다(24종). 표에 없는 낱말도 소리를 가리키면 **낱말 소리**로 그 문장 자리에 놓습니다(11종 · 아래 표 마지막 줄).

| 사건 | 찾는 낱말 (일부) | 예 |
|---|---|---|
| 물방울 | 물방울 · 떨어지 · 똑똑 · 빗물 | "천장에서 물방울이 떨어진다." |
| 종이 | 종이 · 페이지 · 넘겨 · 서류 · 바스락 | "페이지 속 잉크 글씨는 … 지워졌다." |
| 전기 험 | 형광등 · 깜박 · 전구 · 불빛 | 형광등·불빛 문장 (장면 2~4) |
| 균열 · 액체 · 금속 · 둔탁 … | 금이 · 갈라 / 웅덩이 · 냉동액 / 철판 · 녹슨 / 쿵 · 발자국 | 비유(…처럼)·부정(…없는)은 거른다 |
| ✎ 낱말 소리 | 손 · 손끝 → 손 스침 / 글씨 · 잉크 → 펜촉 긁힘 / 가슴 · 정맥 → 박동 / 벽 · 타일 → 두드림 / 먼지 → 사각임 / 소매 · 팔 → 천 스침 | "손가락 마디마디에서 물방울이…" → 1:04 손 스침 |

- **근거 문장마다 한 번은 그 자리에** — 사건이 여러 번 나와도, 그 사건을 부른 문장 자리에는 반드시 한 번 놓는다(닻). 나머지는 그 둘레에 흩는다.
- **정적 문장 → 비우기** — '고요 · 적막 · 소리 없이' 문장 자리는 전체 음량을 65% 낮춘다.

### 꿈의 물리 법칙 → 소리 규칙

| 법칙 | 소리에서 |
|---|---|
| 빨라지는 간격 | 장면 뒤로 갈수록 사건이 촘촘해진다 (장면 1: 1:00 이후 물방울이 0.3~0.7초 간격) |
| 원인보다 먼저 오는 소리 | 소리를 거꾸로 뒤집어 '차오르다가' 그 순간에 끝난다 |
| 삼켜지는 소리 | 닿는 순간 35ms 만 남기고 끊는다 |
| 매번 다른 크기 · 낮아지는 소리 · 공간 연동 | 크고 작게 번갈아 / 음높이·음량이 처짐 / 잔향이 점점 길어짐 |

## 1. 읽기 ② 그림 수치 → 어떤 음색 (교차감각 대응)

**배경 사진 → 공간과 방의 공기**
- 밝기 → 밝을수록 밝은 소리(목표 밝기)
- 암부 비율 → 어두울수록 저역·지속음
- 윤곽 밀도 → 룸톤 알갱이의 결
- 깊이 → 깊을수록 긴 잔향

**오브제 실루엣 → 울림 (모달 합성)**
- 면적 ↑ · 밝기 ↑ → 낮은 음 · 높은 음
- 각짐 ↑ → 날카롭고 비조화 · 짧게
- 대칭 ↑ → 조화로운 배음
- 조각 수 → 뒤따르는 작은 타격

```text
기본음     f0  = 70 · 2^( 4 · (0.55·(1 − √면적) + 0.45·밝기) )   Hz
배음비     r_k = k · √(1 + B·k²),   B = 0.0005 + 0.06·각짐·(1 − 0.6·대칭)
울림 길이  T60 = 0.25 + 2.6 · 단단함 · (1 − 0.6·각짐) · (0.5 + 면적)   초
```
*계수의 방향은 교차감각 대응 연구(Spence 2011 · Frontiers in Psychology 2024)를 따르고, 크기는 휴리스틱 — 청취 평가로 보정하는 것이 후속 과제.*

## 1. 읽기 ③ 그림 인식 → 무슨 소리 (10-08 추가)

②만으로는 그림이 **무엇인지** 모릅니다 — 종이 물체가 쇠처럼 울릴 수 있고, 배경에 형광등이 보여도 그 소리가 나지 않습니다. 그래서 상업 이용이 가능한 공개 모델 셋으로 그림을 읽습니다.

| 모델 | 라이선스 | 묻는 것 | 소리에서 바뀌는 것 |
|---|---|---|---|
| **SigLIP 2** (Google · 2025) | Apache-2.0 | 정해 둔 낱말 목록 중 무엇에 가까운가 · 재질 9종 · 장소 12종 | 오브제 재질 → 울림의 성격 (종이: 짧게 '사각' · 금속: 길고 비조화 · 유리: 높고 맑게 · 액체: 기포처럼 위로 휨) / 장소 → 잔향 출발점 (복도 2.6초 · 서가 1.1초 · 동굴 5.5초 …) |
| **Florence-2** (Microsoft · 2024) | MIT | 그림 속 물체와 위치 · 그림 설명 문장 | 배경에 보이는 소리원이 그림 속 좌우 위치에서 남 / 오브제가 무엇인지 → 정체 소리 |
| **Depth Anything V2 Small** (2024) | Apache-2.0 (Small 만) | 배경의 깊이 지도 | 공간의 깊이 → 잔향 길이 · 소리원까지 거리 → 멀수록 작고 먹먹하게 |

### 그림 속 물체 → 소리 (소리원 분류표의 일부)

- 형광등 · 전구 · 램프 → **전기 험** / 창문 · 거울 · 병 · 유리 → **유리** / 시계 · 진자 → **째깍**
- 책 · 책장 · 서류 · 일지 → **종이** / 파이프 · 수도꼭지 → **물방울** / 웅덩이 · 액체 · 잉크 → **액체**
- 사슬 · 열쇠 · 쇠 → **금속** / 의자 · 선반 · 계단 → **삐걱임** / 그림자 · 형체 · 연기 → **존재감**

### 두 가지 방식으로 재생

- **배경의 소리원** — 이야기에 없어도 낮게 난다. 예: 배경 왼쪽 위에 형광등 → 전기 험이 왼쪽에서, 깊이 지도상 멀면 작고 먹먹하게. 이야기에도 같은 사건이 있으면 그 사건이 그림 속 위치에서 들린다.
- **오브제의 정체 소리** — 오브제가 나오는 문장 자리에서. 장면 1(이번 결과):
  - 0:27 · 1:01 · 1:14 종이 — 낡은 항해일지 (logbook)
  - 0:08 · 0:42 · 1:04 액체 — 푸른빛 냉동액 웅덩이 (puddle)
  - 0:54 · 1:11 존재감 — 팔이 긴 부유하는 그림자 (shadow)
- **빠르게** — 결과는 그림 지문(SHA-256)별로 `cache/vision/` 에 저장 → 같은 그림은 다음부터 0초. GPU 면 처음에도 장면당 몇 초.
- **없어도 돈다** — torch 가 없거나 모델을 못 받으면 ③만 건너뛴다. 정체 소리는 오브제 팀 영어 이름표(OBJ_ENGLISH_MAP)로 대신 정한다 (이번 미리듣기가 이 경우).

| 조각 | 어디서 왔나 | 어떻게 만드나 (전부 numpy/scipy 수식) |

## 3. 진화 — 가장 듣기 좋은 구성 찾기

**무엇을 바꾸나** — 조각 자체와 시각(문장 자리)은 1·2단계가 정했으므로, 진화는 **구성**만 바꿉니다. 유전자 15개: 층별 음량 4 (룸톤 · 오브제 · 이야기 사건 · 그림 소리) · 사건 빈도 · 문장 자리에 몰리는 정도 · 오브제 울림 빈도 · 문지름 · 룸톤 알갱이 결 3 · 좌우 폭 · 잔향 길이 · 비율 · 흡음
**어떻게 고르나** — 후보마다 8초 미리듣기를 만들어 **듣기 좋은 정도** 8가지를 잽니다(각 0~1, 가중합).

| 항목 | 재는 법 | 근거 |
|---|---|---|
| 잡음 적음 | 스펙트럼 평탄도가 낮을수록 (쉬익 대신 음이 있는 소리) | 10-07 층별 측정 — 잡음의 주원인 |
| 날카롭지 않음 | 4kHz 위 에너지 비율 | Fastl & Zwicker · DIN 45692 날카로움 |
| 탁하지 않음 | 귀의 감도(A 가중)로 본 250Hz 아래 비율 | IEC 61672 A 가중 |
| 떨림 없음 | 음량 포락선의 20~150Hz 변조 비율 | ECMA-418-2 (2022) 거칠기 대역 |
| 붐비지 않음 | 초당 놓인 소리 0.4~1.8개 | ISO/TS 12913-3 (2019) 쾌적–사건성 |
| 층 균형 | 어느 층도 가장 큰 층보다 10dB 넘게 묻히지 않고, 룸톤이 가장 크지 않게 | 사운드스케이프의 전경/배경 (Mitchell et al. 2022) |
| 사건이 들림 | 앞소리가 룸톤보다 4~14dB 위 | 사운드스케이프의 전경/배경 |
| 그림 부합 | 소리의 밝기 ≈ 배경 밝기에서 나온 목표 | 교차감각 대응 |

> 🧬 **탐색 = MAP-Elites** — 격자(밝기 8칸 × 밀도 8칸)의 칸마다 가장 듣기 좋은 구성을 보관 → 성격이 다른 좋은 후보를 동시에 키운다. 출발점은 막(배경 엔진 AUDIO_ACTS) · 배경 사진 · 장소에서 나온 값. 장면 4개를 CPU 코어에 나눠 동시에, 시간 예산이 닿으면 그 자리에서 멈춤. 마지막에 앞 장면과 성격이 다를수록 조금 가산.

## 4. 렌더 — 배치 · 작곡 · 꿈의 변형 · 공간

고른 구성으로 장면을 정확히 75초로 만듭니다. 쌓는 순서:
1. **배치** — 사건은 문장 자리에(꿈의 법칙) · 오브제는 이름이 나오는 문장 자리에 · 그림 소리원은 그림 속 좌우 위치에 · 룸톤은 장면 내내
1. **혼합** — 층별 음량·폭 = 3단계가 고른 값
1. **작곡** — 배경 분위기 → 선법·화성 패드 · 4장면을 관통하는 동기 · 화음에 맞춘 방의 공명
1. **꿈의 변형** — 이질적 침입 · 음색 치환 · 변신 · 데자뷔
1. **공간 · 곡선** — 지속음 · 잔향(깊이·장소) · 기승전결 음량 곡선 · 정적 비우기 · 음량 맞춤

### ③ 배경 분위기에 맞는 작곡 (composition.py)

**분위기 = 배경 그림 65% + 이야기 감정 35%** — 배경: 밝고 따뜻할수록 긍정, 채도·대비가 클수록 각성 (Jonauskaite et al. 2020) + 인식된 장소(숲·들판 +, 동굴·지하실 −)

| 분위기 | 선법 |
|---|---|
| 부정 · 높은 각성 | 프리지아 (♭2의 불안) |
| 부정 · 낮은 각성 | 에올리안(단조) · 도리아 |
| 긍정 · 높은 각성 | 리디아 |
| 긍정 · 낮은 각성 | 이오니아(장조) · 믹솔리디아 |

| 장면 | 정서가 | 각성 | 선법 · 조성 |
|---|---|---|---|
| 1 기 | −0.55 | +0.21 | A 프리지아 |
| 2 승 | −0.50 | +0.23 | D 프리지아 (+5) |
| 3 전 | −0.53 | +0.38 | B♭ 프리지아 (+1, 긴장) |
| 4 결 | −0.58 | +0.12 | A 에올리안 (돌아옴) |

- 화음은 **이야기 문장 경계**에서 바뀜 (장면 1: 0:00 I → 0:20 VI → 0:38 IV → 0:57 I)
- 동기: 5음 주제(시드 "낡은 항해일지")가 원형 → 반복 → 뒤집기 → 느린 확대, 음색은 오브제 실루엣의 배음

### ④ 꿈의 변형 (dreamfx.py) — 효과음을 그대로 두지 않는 자리

| 장치 | 무엇을 하나 | 장면 1 에서 |
|---|---|---|
| 이질적 침입 | 장면 정서와 반대되는 소리가 좌↔우로 지나감 · '갑자기·스스로…' 문장 자리 (아래 목록) | 0:58 먼 아이 웃음 · 1:10 실로폰 동요가 지나감 |
| 음색 치환 | 이야기에 없는 생물의 몸짓을 장면 재질의 음색으로 ("철판으로 퍼덕이는 날개") · 새 우선 없음 (아래 목록) | 0:19 날갯짓 × 녹슨 철판 · 1:02 고래 노래 × 냉동액 웅덩이 실루엣 |
| 변신 | 한 소리가 몇 초에 걸쳐 오브제 소리로 바뀜 (배경의 점진적 모핑과 같은 원리) | 0:36 액체 → 낡은 항해일지 (9초) |
| 데자뷔 | 앞에서 들린 소리가 뒤에서 낮게·거꾸로·멀리 되돌아옴 | 1:07 액체가 느리게·거꾸로 |

**꿈의 변형에 쓰는 소리** — 이야기에 이미 나온 소리는 빼고, 꿈 전체에서 한 번 섞은 순서를 장면마다 밀어 가며 꺼낸다 → 네 장면이 서로 다른 소리를 듣는다.

| 종류 | 소리 |
|---|---|
| 이질적 침입 — 어두운 장면에 (밝은 소리 14종) | 오르골 · 새의 지저귐 · 풍경 · 먼 휘파람 · 하프 · 허밍 · 거품 · 귀뚜라미 · 먼 피리 선율 · 실로폰 동요 · 칼림바 · 자전거 벨 · 먼 아이 웃음 · 태엽 장난감 |
| 이질적 침입 — 밝은 장면에 (어두운 소리 12종) | 낮은 으르렁 · 쇠 긁힘 · 심장 박동 · 먼 뱃고동 · 느린 노크 · 부엉이 · 먼 사이렌 · 먼 천둥 · 보이지 않는 발소리 · 낮은 징 · 열리는 문 · 속삭임 |
| 음색 치환 — 생물의 몸짓 (16종) | 새 · 귀뚜라미 · 심장 · 숨 · 개구리 · 고양이 · 날갯짓 · 부엉이 · 고래 · 개 · 늑대 · 벌 · 갈매기 · 돌고래 · 매미 · 뻐꾸기 |
| 음색 치환 — 재질의 음색 | 녹슨 철판 · 형광등 전기 험 · 종이 · 얼음·유리 · 액체 · 나무 · 돌·타일 · 오브제 실루엣 (장면의 재질 순위에서) |

이번 결과에서 나온 것 — 장면 1: 아이 웃음 · 실로폰 / 날갯짓 · 고래 · 장면 2: 태엽 장난감 · 피리 / 고양이 · 심장 · 장면 3: 오르골 · 거품 · 칼림바 / 늑대 · 뻐꾸기 · 장면 4: 새 · 귀뚜라미 / 돌고래

*세기는 막이 정한다 — 전(정점)에서 가장 세고 결에서 약하게. 장치 종류가 정해져 있어 '지나치게 열린' 결과는 나오지 않는다.*

### ⑤ 공간과 장면 잇기

장소·깊이로 잔향 길이를 정하고(장면 1: 3.7초 → '공간 연동' 법칙으로 5.9초까지 커짐), 기승전결 곡선(기 차오름 · 승 머묾 · 전 정점 · 결 사라짐)을 곱합니다. 장면 경계는 배경 화면 모핑과 같은 **2.8초** 동안 겹쳐 섞고 양쪽 음량을 맞춥니다. 결 장면만 −3dB.

### 저작권 · 상업 이용

출력 소리의 모든 표본은 우리 코드가 수식으로 계산 — **외부 음원 0개 · 생성 모델 출력 0개** → 제3자 저작권이 섞일 경로가 없고 상업 이용 제약이 없다. 그림 인식 모델 셋은 그림을 읽어 숫자만 내며 모두 Apache-2.0 · MIT. 실행마다 provenance.json 에 조각 출처 · 모델 라이선스 · 코드/입력 지문이 남아 재현으로 확인할 수 있다. (근거: LICENSE_AUDIT.md — 법률 자문은 아님)

### 실행 방법 (저장소 루트에서)

```bash
pip install -r team3/sound/requirements.txt          # 이것만으로도 돈다 (그림 인식 없이)
pip install torch --index-url https://download.pytorch.org/whl/cu130   # 그림 인식용 (본체 CUDA 에 맞게)
pip install -r team3/sound/requirements-gpu.txt
python team3/sound/generate_sound.py                 # 처음 한 번 모델 약 2.5GB 내려받음
python team3/sound/generate_sound.py --mux 영상.mp4   # 영상에 소리 붙이기 (몇 초)
```

> ⚠️ **아직 확인할 것** — 작업 환경에서 Hugging Face 접속이 막혀, 그림 인식은 같은 구조의 시험용 모델과 가짜 인식 결과로 **코드가 끝까지 도는 것만** 확인했다. 실제 인식이 얼마나 맞는지는 데스크톱 첫 실행에서 해설 자료의 👁 줄로 확인하고, 엉뚱한 소리가 있으면 낱말 목록(SOURCE_RULES · 재질·장소 목록)을 다듬는다. 이 문서의 수치는 그림 인식 없이 돌린 결과다.
