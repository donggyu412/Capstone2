꿈의 소산 — 기승전결 파티클 드리밍
캡스톤 디자인2 · 3팀 · 시스템 I (꿈 배경 이미지 생성)

원본 사진은 화면에 그대로 나오지 않습니다.
사진은 보이지 않는 캔버스에만 깔리고, 14000개의 빛 파편이 그 위를 떠다니며
자기 자리의 픽셀 색과 밝기를 머금고 점으로 내려앉습니다.
형태는 '그려지는' 것이 아니라 기승전결에 따라 맺혔다 풀립니다.

	기  파편이 자리를 못 잡고 사방으로 흩날린다
	승  제 자리에 안착해 형태가 아스라이 뜬다
	전  가장 밝은 빛으로 소용돌이치며 빨려들고 노출이 터진다
	결  모든 속도가 죽고 짙은 안개가 형체를 여백으로 지운다

※ 이 문서는 '지금 어떻게 쓰고 무엇이 돌아가나'만 적습니다(2026-09-28 기준).
  값을 왜 그렇게 정했는지 · 실측 · 실패한 시도는 IMPLEMENTATION_LOG.md (09-13 이전 옛 기록은 1001 폴더 docs/LOG_ARCHIVE.md).

4. 입력 — 2팀 스토리보드 (input/storyboard/)

	[놓을 자리]  input/storyboard/*.json (여러 개면 가장 최근 파일). 새로고침만 하면 다시 읽습니다.

	[2팀 형식]  {"scenes": [{ "scene", "story", "backgrounds", "objects", "emotions",
	                          "physics_laws", "main_emotion": {"label", "intensity"}, "vector" }, …]}

	[우리가 읽는 방식]
	  scene 순서      → 기·승·전·결 (합의 단위가 기승전결 4장면)
	  backgrounds     → 배경 사진의 프롬프트 · 첫 항목이 장면 제목 · 참조 작가를 부르는 주 근거
	  main_emotion    → 감정 라벨·세기 (1팀 7종). 없으면 옛 emotion → emotions 문장 짐작 순
	  physics_laws    → 배경 현상 6종만 파티클 물리로 (7장). 오브제·소리 법칙은 옮기지 않는다
	  story           → 공기 중의 물기 · 참조 작가(보조)
	  objects         → 그리지 않는다(시스템 II 몫). 프롬프트의 '들어가면 안 되는 것'과 물기 거르기에만
	  vector          → 쓰지 않는다 (2팀 내부값, 09-27 확정)

	[배경 사진 만들기 — 지금은 이미지 생성기에 수동]
	  1) python tools/make_prompts.py → input/storyboard/prompts.txt (장면별 문장)
	  2) 문장을 ChatGPT 등 이미지 생성기에 붙여넣는다. 가로 16:9 · 1280px 이상

	  ※ 프롬프트에 작가 이름은 넣지 않습니다. 생성기는 '무엇이 있는 장면인가'만,
	    '어떻게 꿈이 되는가'(아피찻퐁 스타일)는 우리 엔진이 입힙니다.
	  ※ 사진이 없는 장면은 터미널·패널에 필요한 파일명이 뜨고 그 장면은 건너뜁니다.

5. 기승전결 물리 — index.html 의 ACTS 표

	막이 바뀌면 입자에 걸리는 힘의 종류가 바뀝니다. 값은 170프레임에 걸쳐 서서히 끌려갑니다.

	     막   안착   카오스 소용돌이 마찰   빛    안개  번짐   붙들기 제자리 비움  바탕
	     기   0.000  1.30   0.00    0.962  0.75  0.62  1.00   0      0.50   0     1.0
	     승   0.026  0.10   0.00    0.840  0.95  0.34  0.55   0      0      0.60  1.0
	     전   0.002  0.34   0.40    0.930  2.10  0.30  1.30   0.040  0      0     1.0
	     결   0.000  0.03   0.00    0.780  0.55  1.00  1.60   0      0.50   0     2.0

	안착(settle)   제 자리로 끌리는 힘 — 승에서 형태가 맺힌다
	카오스(chaos)  방향 없는 가속 — 기에서 흩날린다
	소용돌이(swirl) 가장 밝은 점으로 빨려들며 돈다 — 전
	붙들기(hold)   어두운 파편만 제 자리로 — 전의 소용돌이 속에도 윤곽이 남는다
	제자리(home)   다시 태어나는 파편 중 제 자리에서 태어나는 비율 — 점의 밀도로 형체가 선다
	비움(sparse)   평평한 중간 톤에 앉은 파편을 비워 화면 안 여백을 만든다 — 승
	바탕(base)     원본 바탕(BASE_ALPHA 0.01)의 막별 배율 — 결만 2.0
	               (어두운 사진에선 파편이 형체를 못 그린다. 결의 서가가 안개 너머로 흐릿하게 비친다)
	※ 09-28: 전 붙들기 0.020→0.040 · 결 바탕 2.0 — 전·결에도 원본의 흔적을 남긴다(사용자 육안 확정, LOG 40).


6. 그 밖의 시각 규칙 (근거·실측은 LOG)

	픽셀 샘플링   입자가 자리의 색·밝기를 머금는다. 어두운 픽셀 위 입자는 거의 안 보여 형태가 '빛으로만' 드러난다
	노출 보정     이미지 중간 밝기가 LIFT_MID 0.36 에 닿도록 감마(하한 0.40) — 어두운 사진의 형체를 살린다
	노출 제한     원본 평균 밝기 × 막 빛 배율이 GLOW_CAP 0.50 을 넘으면 빛을 낮춘다(밝은 사진 × 전)
	번짐 크기     GLOW_SIZE 0.7 (09-27 확정)
	원본 바탕     BASE_ALPHA 0.01 — 형체를 돕되 '사진 + 필터'로 보이지 않는 선(09-27 사용자 결정)
	점진적 변형   장면이 바뀔 때 옛 자리 → 새 자리로 파편을 끌고 간다(Z-order 짝짓기, 약 2.8초)
	여백          결 → 기에서만 2.5초 비움 + 3초 정적. 그 밖의 전환은 비우지 않고 변형
	안개          직전 화면을 살짝 키워 되얹고(번짐) 어둠·안개색으로 덮어 삭힌다
	바람          위치마다 세기·방향이 다른 돌풍 — 유전자 freq·turb·amp 가 결을 정한다
	해체          장면이 진행될수록 샘플 좌표가 흔들린다 — 세기는 GA 돌연변이율
	서사 표지     막 · 제목 · 감정을 캔버스 안(좌하단)에 그린다 — 캡처·녹화에도 이야기가 따라간다
	구도 비네트   막별 아피찻퐁 구도 지도로 화면 비네트를 건다(세기 0.80 고정)

	     기   -3.0반음  0.60              60~900Hz       물속처럼 먹먹하고 낮게
	     승   -0.9반음  0.45              40~6000Hz      귀가 트이고 원음에 가깝다
	     전   +1.0반음  0.85 (긴 잔향 30%) 90~16000Hz     피치가 오르고 공간이 넓어진다
	     결   -4.3반음  1.00 (긴 잔향)     250~1200Hz     벽 너머, 낮게 늘어지며 사라진다

	창발 변조 — DB 근접도 → 잔향, 유전자 freq → 호흡 주기(7.9~14초), turb → 호흡 깊이, spiral → 피치 요동.
	필터 대역과 음량 보정(make)은 FFT 실측값이라 건드리지 않는다(변환 전후 0dB, 결만 −3dB).
